# 角色台词总览（Slay the Spire 2 / Godot C#）

> 分析视角：单人版（默认排除联机/同步层）。文本以 `localization/zhs/` 简体中文为准，`eng/` 作对照。
> `⏎` 代表本地化原文里的换行；方括号标签（`[gold]`、`[sine]`、`[jitter]`、`[i]`、`[font_size]` 等）为 MegaText 富文本标记，`{Xxx}` 为运行时占位符，均按原文保留。
> 本文只收**系统化的可显示台词键**（`talk.*` / `banter` / `speakLine*` / `*Line` / `dialogue`）；事件叙述正文里的对白（如 `CRYSTAL_SPHERE.pages.*.description` 中的引号句）属叙事文本，不在此列。

## 0. 先给结论：三类说话人并非同场

| 场景 | 商人 | 玩家角色 | 敌人 |
|---|---|---|---|
| 普通商店（Shop 节点） | **说话**，16 条 | 不说话 | 不出现 |
| 「商人？？？」事件（`FAKE_MERCHANT`，未知节点可揭晓） | **说话**，34 条 | 不说话 | 识破后变身为 `FAKE_MERCHANT_MONSTER`，**说话** 5 条 |
| 战斗 / 事件 / 先古之民房间 | — | **说话** | **说话**（26 条分散于 13 个怪物） |

因此「商店中玩家、敌人会讲什么」的准确答案是：**玩家在任何商店场景都没有台词**；敌人只在假商人事件的战斗阶段开口。玩家角色的话分布在事件、先古对话、回合提示与操作失败提示里。

### 2.3 触发链路（代码）

1. `MerchantRoom.Dialogue`（`src/Core/Rooms/MerchantRoom.cs:29`）用 `GetLocStringsWithPrefix("MERCHANT.talk.")` 一次性取全部键；假商人在 `FakeMerchant.cs` 用 `FAKE_MERCHANT.talk.` 前缀，走同一套逻辑。
2. `MerchantDialogueSet.CreateFromLocStrings()` 按 key 倒数第二段分入 8 个列表：`welcome / openInventory / foulPotion / playerDead / purchaseSuccess / purchaseFailureGold / purchaseFailureSpace / purchaseFailureForbidden`；出现未知类别直接抛异常。
3. 播放时统一 `Rng.Chaotic.NextItem(列表)` **随机取一条**；`NMerchantDialogue.ShowRandom()` 用 `[fly_in]` 包裹，气泡 0.25s 弹入 → 停留 1.0s → 0.5s 淡出，且 x 坐标在 450~1450 间随机。
4. 调用点：`NMerchantInventory`（打开货架 → `OpenInventoryLines`；购买结果 → `GetPurchaseSuccessLines(status)`）、`NMerchantRoom` / `NFakeMerchant`（点商人 → `PlayerDeadLines`；恶臭药水 → `FoulPotionLines`；假商人入场 → `WelcomeLines`）。

### 2.4 真假商人的设计差异（易踩点）

- 真商人**没有 `welcome` 与 `openInventory` 键**，因此打开商店时不说话；只有购买成败、被泼药水、玩家死亡才开口。假商人则进门即吆喝、开货架时持续碎嘴——文案量 16 → 34，语气也从客气（「感谢惠顾」）变成心虚话多（「你没在附近见到过什么哨卫吧？」）。
- 两者共用同一 `MerchantDialogueSet`，所以**新增类别必须同时改 8 分支的 switch**，否则解析时抛 `InvalidOperationException`。
- 假商人事件还有 `FAKE_MERCHANT.title` = 商人？？？、`.loss` = {character}面对了[gold][b]{event}[/b][gold]的怒火。；`pages.INITIAL.description` 目前是占位符。

## 5. 相关的 NPC 对话：先古之民

不属于用户问的三类，但与「谁在讲话」直接相关，给出结构以便检索：

- `ancients.json` 共 409 个 `talk` 键 = `ancient` 台词 212 + `char` 玩家台词 75 + `next` 按钮文字 122。
- 9 位先古：`DARV` 48、`NEOW` 45、`NONUPEIPE` 36、`OROBAS` 40、`PAEL` 32、`TANX` 46、`TEZCATARA` 48、`THE_ARCHITECT` 61、`VAKUU` 53（含按钮文字）。

## 6. 语音（VO）资源与文本台词的关系

**两者不是一一对应**：本地化台词是文字气泡；`_MyArt/Audio/` 下的 VO 是无语义的喊叫 / 情绪声，不存在「某句台词的配音」。

| 目录 | 文件数 | 内容 |
|---|---|---|
| `_MyArt/Audio/05_角色语音_VO/` | 440 mp3 | 21 个实体，动作含 `hurt / die / attack / greeting / impatient / triumphant / welcome / laughter / roar` 等 |
| `_MyArt/Audio/07_怪物与角色专属/` | 275 | 怪物与角色专属音效（非语音） |

- 商人 VO 14 个：`welcome` 4、`thank_yous` 3、`dissapointment` 3、`laughter` 2、`passive` 2；另有 `reverse_merchant`（假商人）约 13 个（含 `hehe` / `hurt_sad` 等）。
- 玩家角色 VO 目前只检出 `regent`（储君）70 个（`greeting / impatient / hurt_low|mid|high / die / attack / triumphant` 等）；其余 4 个角色没有对应 VO 命名。
- 先古 / 怪物 VO：`darv` 20、`tanx` 17、`nonupeipe` 16、`twotailrats` 37、`kin` 43 等，配合 §5 的对话行或战斗事件播放。
- 命名格式：`sfx_NNNN_sts2_sfx_VO_<实体>_<动作>_vN_rrN.mp3`（`rrN` = 随机轮替变体）。

## 8. 易踩点小结

1. **真商人打开商店不说话**：缺 `welcome` / `openInventory` 键，`NextItem(空列表)` 返回 null 直接跳过；只有假商人才会迎客与碎嘴。
2. **新增台词类别要改代码**：`MerchantDialogueSet` 的 switch 是白名单，未知类别抛异常；key 的倒数第二段必须是 8 个类别名之一。
3. **随机而非顺序**：同类别多句一律 `Rng.Chaotic.NextItem`，不存在固定播放顺序，也无需按 `lineN` 编号推断剧情先后。
4. **单人版**：`banter.*.endTurnPing` 10 条走联机 `FlavorSynchronizer`，单人不会出现；`combat_messages.json` 的「我没有队友」也是联机语境残留。
5. **`talk` 键不只商人**：`ancients.json` 的 409 个 `talk` 键里只有 75 条是玩家说的，212 条是先古说的，122 条是按钮文字，按后缀区分。
6. **旁白不是台词**：`.char` 里 `[i][font_size=22]…[/font_size][/i]` 是动作描写，静默猎手大量以「……」代替发言。
