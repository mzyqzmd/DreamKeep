# 《尖塔梦境》世界观与背景设定

## 0. 项目名与游戏名的解耦说明

| 名称 | 用途 | 是否可变 |
|------|------|---------|
| **DreamKeep** | 工程代号：代码仓库名、程序集名（`_DreamKeep.*.asmdef`）、项目根目录 | 建议保留，改动成本高 |
| **尖塔梦境（Dream Spire）** | 游戏名：毕设展示、文档标题、对外品牌 | 可改，见第 2 节 |

**核心结论：项目名不影响游戏设计。** DreamKeep 是技术层面的代号，游戏叫什么、世界观是什么，由设计文档决定，二者无需一致。本文档以《尖塔梦境》为游戏名展开，后续若更名，仅替换标题与术语表中的游戏名即可，不影响工程结构。

## 1. 项目定位

《尖塔梦境》是一款以"梦之尖塔"为舞台的肉鸽卡牌构筑游戏。核心战斗在**能量-手牌-意图**的循环上展开，并引入"前排优先级"与"敌人前进触发特殊意图"两条空间规则，使每层战场呈现为一条向上延伸的梦境走廊：被困的梦魇从走廊深处逼近，最前方的存在必须被优先净化。

本文档只涉及世界观、背景与叙事包装，不涉及具体数值、卡牌效果、关卡结构或玩法系统细节。

## 2. 游戏名称

**推荐游戏名：尖塔梦境（Dream Spire）**

命名逻辑：

- **尖塔**：直接呼应现有素材的空间结构（层层向上、每层一个战场），也点明这是一座"塔"而非开阔世界；
- **梦境**：定义舞台属性，为怪物、法术、遗物提供统一隐喻来源；
- **英文 Dream Spire**："Spire" 兼具尖塔与"向上攀升"之意，比 "Tower" 更轻盈，贴合"登向黎明"的基调。

备选（若觉"尖塔"仍偏暗，可换）：

| 候选 | 含义 | 适合度 |
|------|------|--------|
| 尖塔梦境 | 直接、贴合素材 | 高 |
| 晨塔（Dawn Spire） | 强调"登顶见光"的阳光目标 | 高（更阳光） |
| 引梦者（Dreamwarden） | 强调守梦人身份 | 中 |

## 3. 核心意象

- **尖塔**：一座贯通"清醒"与"深梦"的高塔。塔越高，离清醒越近、离黎明越近；塔越深，梦境越浓、魇越重。攀爬尖塔 = 穿越层层梦境。
- **梦魇**：不是天生的恶，而是"被困、迷途、在梦中挣扎"的意识碎片。它们攻击你，是因为在梦里失去了方向，而非本性凶残。
- **灯火**：守梦人随身的一点清醒之光，是你要在战斗中守护的核心，也是引导迷途者归位的信号。前排机制即"梦魇冲向灯火，必须先接住最近的"。
- **黎明**：塔顶的目标。登顶意味着唤醒沉睡者、让晨光照进梦境。这是整个游戏阳光基调的落点。

## 4. 世界观

### 4.1 梦之尖塔

人入睡后，意识会沉入一座无形的尖塔。塔的每一层都是一个独立的梦境：浅层是白日残留的琐碎，深层是 buried 最深的恐惧与执念。通常情况下，黎明到来时所有人会自动沿塔苏醒，梦境消散。

但这一次，塔底的"晨门"被封住了。

沉睡者无法醒来，意识卡在塔里一层层打转。更糟的是，困得越久，梦境越浓，本该安睡的意识开始被梦魇裹挟、失控。若不清障，整座塔会沉入永夜。

### 4.2 守梦人

"守梦人"是少数能在塔中保持清醒自我的人。你的任务不是征服尖塔，而是：

- 沿塔一层层向上，把被困、失控的意识轻轻引导回清醒；
- 净化裹挟它们的梦魇——不是消灭，而是让迷途者重新认得自己；
- 最终抵达塔顶，重新打开晨门，让黎明降临。

每一次在塔中力竭，你都会在底层浅梦处重新醒来，继续攀登。这也呼应肉鸽游戏的"从头再来"：每一次循环，都是离黎明更近一点。

### 4.3 尖塔的层级

| 层级 | 名称 | 视觉关键词 | 叙事含义 |
|------|------|-----------|---------|
| 底层 | 碎梦回廊 | 暖色微光、熟悉的生活剪影 | 白日残留、最易被引回的梦境 |
| 中层 | 执念长廊 | 重复结构、镜面、低饱和绿蓝 | 被强烈情绪困住的意识 |
| 高层 | 沉眠之巅 | 极静的暗、远处一线晨光 | 最接近清醒、也最接近黎明 |

战斗主要发生在"执念长廊"：一条向塔心延伸的走廊，梦魇从深处向你与你的灯火聚拢。

## 5. 背景故事

> 你合上眼时，没有醒来，而是站进了一座塔。
>
> 塔很安静，安静得能听见自己的心跳。每一层都是一条走廊，墙后是些熟悉又模糊的东西——某个清晨的窗、一句没说完的话、一个你想再见一面的人。它们漂在半空，像被按了暂停。
>
> 走廊深处有光点在动。
>
> 它们不是在追你。你能感觉到：那是些迷了路、在梦里越陷越深、开始慌乱挣扎的意识。最前面的那个冲得最急，因为它离你的灯火最近，想被照见、想回家。它伤到你，只是因为它忘了自己是谁。
>
> 你手里握着几枚发亮的小片。那是你清醒时攒下的东西：一句善意、一段安宁、一个不愿弄丢的念头。你要在它们扑到灯火前，把它们轻轻接住、送回去。
>
> 你是守梦人。塔顶有一扇门，门后是黎明。你要把它打开。

## 6. 玩家身份

玩家是一名守梦人，性别、外貌可自定义。核心特征：

- **清醒的攀登者**：在塔中保持自我，不为梦魇所夺；
- **引路者**：卡牌代表被唤起的心意与清醒之力，使用它们是在为迷途者指路；
- **孤独但不冰冷**：塔中无同伴系统，但每次"帮助"都以事件、遗物、卡牌的形式，来自某个曾被温柔对待过的瞬间；
- **倾听者**：梦魇的形态暗示它们源自某段未安放好的记忆，你在攀登中逐渐拼出整座塔为何封门。

## 7. 敌人与世界观

这里的"敌人"是被梦魇裹挟、失控的意识，本质是待救赎的迷途者，而非天生之恶：

| 素材原型（参考） | 世界观解释 | 与前排机制的呼应 |
|----------------|-----------|-----------------|
| 史莱姆类 | 被黏稠梦魇包裹、已看不清原形的记忆团 | 数量多、缓缓涌向前排 |
| 守卫 / 傀儡类 | 被执念驱动、失去自我的傀儡意识 | 占据前排，挡住登塔通路 |
| 低语 / 邪教徒风 | 被梦中低语蛊惑、陷入狂乱的梦游者 | 抵达前排时显露出最混乱、最需被接住的一面 |
| 凝视类 | 被长久凝视、渴望被理解的孤独意识 | 在前排静静积累，等待被认出 |

敌人"前进到最前槽位触发特殊意图"的设计，叙事化为：

> 当一段失控的意识终于冲到你面前、停在灯火最近处，它会显露出最真实、最慌乱的模样——那是它拼命想被你看见、被你引回的最后一搏。

## 8. 视觉风格关联（含素材现状）

当前画面呈现以下特征，与"尖塔梦境"基调的对应：

- **暗绿色与灰蓝色主调**：对应梦境的幽深与塔内的静谧；
- **废墟与剪影背景**：暗示这是一座由众人记忆砌成、略显残破的塔；
- **卡牌边缘的红色与金色**：代表守梦人灯火的余温，是暗中最醒目的暖意，也是"黎明将至"的伏笔；
- **角色与敌人的剪影感**：强调"这不是白日真实，而是塔中投影"。

**素材现状（诚实声明）**：当前战斗美术资源参考 / 复用《杀戮尖塔（Slay the Spire）》的占位素材（怪物剪影、卡牌框、能量图标等）。其哥特暗色调与"梦之尖塔"的幽深基调兼容，因此世界观设计直接采用叙事兼容策略，不强行改写怪物身份。

## 9. 术语表

| 术语 | 含义 |
|------|------|
| 梦之尖塔（Dream Spire） | 连通清醒与深梦的高塔，游戏主舞台 |
| 晨门（Dawn Gate） | 塔底的出口，被封后沉睡者无法醒来 |
| 守梦人（Dreamwarden） | 玩家角色，沿塔引导迷途意识、重开晨门的守望者 |
| 灯火（Wardlight） | 守梦人随身清醒之光，战斗中守护的核心 |
| 梦魇（Nightfold） | 裹挟、困住意识的梦境之力，待净化而非消灭 |
| 碎梦回廊 / 执念长廊 / 沉眠之巅 | 尖塔的三段层级 |
| 前排（Front Slot） | 离守梦人最近、最靠近灯火的位置，最先需净化的所在 |
| 意图（Intent） | 梦魇靠近时显露的状态，抵达前排时更清晰、更需被接住 |

## 10. 设计原则

1. **世界观服务玩法，但不解释玩法**：为什么有塔？因为要一层层登向黎明。为什么敌人前进？因为迷途者向你与灯火聚拢。解释到这一步即可。
2. **留白优先**：尖塔的本质是未知与静谧，叙事宁少勿滥。
3. **一致性高于华丽**：所有文本、敌人命名、事件描述统一使用"塔 / 梦 / 灯火 / 黎明 / 引路"这组隐喻，不混入无关奇幻设定。
4. **暗而有光**：基调承认梦境幽深，但始终指向塔顶的黎明——不走向纯黑暗或绝望，以"登向光"的弧光支撑阳光诉求。
5. **素材诚实**：明确标注占位素材来源，把"叙事兼容"作为设计自觉写进文档，而非假装原创。

## 11. 后续可扩展方向

- 为每个敌人原型补一句"它源自哪类未安放的记忆"的短描述；
- 为关键遗物 / 事件撰写"引路"主题的短篇叙事；
- 为主角写一段开场轻声独白，用于启动时建立登塔氛围；
- 为塔顶"晨门"设计一句点题台词，收束"DreamKeep / 守梦人"的双重含义；
- 美术替换路线：列出需自绘的核心资产清单（守梦人、灯火、三层走廊背景、Boss 剪影），作为毕设工作量的一部分。
