| 后排敌人默认免疫单体攻击（因未接敌） | **决策 N（v3.6 新增）**：**硬阻挡**——未带「指定」或「穿透」的单体效果**不能**选中后排（是规则而非默认值，UI 不亮后排）；敌人按阵型位分**前排（高血低威胁的拦路/守护型）**与**后排（低血高威胁的输出/施法型）**两类定位。理由：取消压境后"阵型"若无硬阻挡则退化为纯默认值、与 StS 自由点选无异；加此规则后"先啃前排 vs 用穿透/指定够后排"仍是每回合真决策，且**不新增任何系统** |
| 词条按展示顺序逐条结算，"特殊[消耗/穿透/目标/遗忘]"排在最后 | **决策 O（v3.6 新增）**：结算改为**两 pass**——**Pass 1 落点解析**：扫描卡上全部「落点修饰型词条」（指定/穿透）合成落点（与词条顺序无关）；**Pass 2 效果结算**：按序遍历效果型词条，共用 Pass 1 的落点。**「指定」+「穿透」同卡不是优先级冲突，而是起点与范围两个正交维度的组合**：起点 = 被指定的敌人，范围 = 从起点一路贯到最后一个。理由：原顺序把穿透/指定排在伤害之后，穿透将永远失效（顺序 bug）；两 pass 天然修正，且"卡是白板、所有玩法语义必须是词条"（§4.4）得以保持 |

## 1. Fun Hypothesis 与 Design Pillars

**Fun Hypothesis（一句话）**：
> 以《杀戮尖塔》意图可读的回合制战斗为脊柱，用**词条组合模型**把卡牌变成"可拼装的积木"，叠加《怪物火车》的**长条纵深战斗空间**（前后阵型编队、前排阻挡后排——车厢灵感的非照抄转写）、《Inscryption》的遗忘词条、《Balatro》的协同套装遗物；**敌我共用同一套 affix 卡与结算管线，敌人的"意图"以槽位多卡呈现、卡面词条完全可读、且可读多回合**——让每回合在**纵深次序、词条组合、遗忘豪赌、套装流派**四个维度上做决策，比纯 StS 更密、仍完全可读，且内容量产成本因组合爆炸而远低于手工设计。

**Design Pillars（5 条，每条标注服务体验、负责系统、机制来源）**：

| # | Pillar | 服务的玩家体验 | 负责系统 | 机制来源 |
|---|---|---|---|---|
| P1 | 完全可读的深度（Readable Depth） | 每次失败怪自己不怪运气；决策前有完整信息，**敌我意图皆以可读敌卡（槽位多卡、可读多回合）呈现** | 意图系统（敌卡化 + 意图槽位）+ 词条清晰可读 + 词条描述 tip（仅名称模式） | StS |
| P2 | 纵深即决策（Depth is a Decision） | 战斗是"突破阻挡"而非点名；谁在纵深前列决定谁被打得到、谁被挡在后面——先啃前排还是用穿透/指定够后排，是每回合的选择 | 战斗系统长条纵深（固定前后阵型、硬阻挡、命中次序）；我方单角色无部署 | Monster Train（车厢灵感的非照抄转写，已简化为"阵型阻挡"） |
| P3 | 卡牌=词条组合，组合即构筑（Cards = Affix Combos） | 卡牌是可组合积木；词条库才是真内容，构筑=选词条 | 词条组合模型 + 奖励三角 | StS 卡框架（工程化产出） |
| P4 | 遗忘即豪赌（Erase as a Gamble） | 舍得忘掉一张牌换爆发；构筑可减不可逆，决策更锋利 | 遗忘词条 + 手牌管理 | Inscryption |
| P5 | 套装遗物与参数化难度（Synergy Relics + Numeric Difficulty） | 流派靠套装遗物成型；重玩靠参数不堆内容 | 遗物系统（协同套装）+ 地图分支 + 难度档 | Balatro + StS 地图 |

## 2. 融合矩阵（Fusion Matrix）—— 本稿重点

**结论先行**：4 款来源各自贡献一个**正交**维度；其中 ① 的词条组合模型还顺带把内容量产成本打下来，并在 v3.1 扩展为**敌我共用**——敌人意图也由该模型生成的敌卡承载。③（Gloomhaven 耐力）与 ⑤（Dicey 重投）已砍，仅「消耗」词条例外保留。

### 2.1 逐源融合表

| 来源 | 借用机制 | 本作定位 | 如何嵌进主循环 | 单人成本 | 为何不撑爆范围 |
|---|---|---|---|---|---|
| **Slay the Spire** | 意图可读战斗 + 状态词表 + 分层地图 + 卡/遗物/药水奖励三角 + **词条组合模型（敌我共用）** | **主干脊柱 + 内容生产方法** | 战斗主循环/地图/奖励三角基于它；词条模型是其卡牌框架的产出方式；**意图系统实现方式升级为"敌卡"——敌人从意图卡组打出 affix 敌卡，不再是抽象数值** | 中（基础但体量大） | 只做 1 角色；词条库敌我共用、复用 → 玩家卡+敌卡模板边际成本极低 |
| **Monster Train** | **长条纵深空间与"阵型阻挡"**：战场是一条纵深通道，敌人按前后阵型编队，前排挡住后排，单体攻击默认只能打到最前（火车车厢灵感的抽象，非照抄） | **空间维度**（战斗空间主轴） | 战场=一条纵深通道，**玩家单角色守近端**；敌人按纵深位编队、**开局全部就位**（无压境倒计时）；攻击默认命中纵深最近敌人，后排需「穿透」/「指定」才能触及 | 中（纵深位 + 命中次序规则；**无部署系统**，比 v3.2 更省） | 只做单列纵深：无多层车厢、无单位铺场、无静态守核（Pyre）、**无逐回合压上**；玩家唯一单位=角色自身 |
| **Inscryption** | 遗忘作为**词条**：带「遗忘(指定词条)」的卡打出时，拖动指向另一张带该词条的牌、将其**遗忘**以强化自身 | **卡牌互动维度（affix）** | 带遗忘词条的卡需拖拽并把目标牌忘掉才能打出 | 低（1 词条 + 拖拽交互） | 不引入 bank 资源；复用现有结算管线 |
| **Balatro** | 协同套装遗物：2~3 件为一组，各件独立生效、零跨遗物耦合，共同奖励某流派 | **遗物系统约束 / 构筑轴** | 折进遗物系统（见 §4.6） | 低（遗物设计约束） | 只是遗物设计原则，不新增系统 |

### 2.2 取舍说明：为什么是这 4 款（及 ③⑤ 砍掉）

| 候选 | 处置 | 理由 |
|---|---|---|
| **Gloomhaven / Card Quest**（耐力第二资源 + 营地回收） | **砍耐力与营地回收**；但「消耗」词条例外保留 | 独立耐力资源 + 营地回收抬高经济复杂度，单人收益低；"打出即离场"的体验已由「消耗」词条承载 |
| **Dicey Dungeons**（重投经济） | **整项移除** | 随机控制维度与"完全可读"部分冗余，且增加一个计数器/按钮的交互面；用户明确砍 |
| **Ring of Pain**（位置脆弱） | 砍 | 与 MT 长条纵深空间思想重叠 |
| **双牌组 / 多角色 / 重叙事 / 完整爬塔 / 无限 combo 放任** | 砍 | 同 v2 排除清单理由 |

### 2.3 明确排除清单（Exclusion List）

1. **Gloomhaven 耐力资源 + 营地"回收消耗卡"** —— 砍；仅保留「消耗」词条（离场效果），营地退化为回血/升级二选一。
2. **Dicey 重投（计数器/按钮）** —— 整项移除。
3. **多角色卡池** —— 内容翻倍，单人不可及。
4. **双卡组（战斗+谈判）** —— 双倍卡池+数值+认知负荷。
5. **牌型构筑（扑克/骰子）** —— 类型不符（非战斗肉鸽）。
6. **重叙事 meta / 规则不稳定** —— 口碑风险高、占预算。
7. **MT 多层垂直车厢 + 单位铺场 / 静态守核（Pyre）** —— 只取"敌人沿纵深逼近"的空间思想，落为**单列纵深编队**；不引入多层车厢、铺兵或"守一座火堆"式目标。
8. **独立"蓄能 bank"资源（原 Inscryption 银行化）** —— 砍，保持精简；遗忘只吃手牌不产资源。
9. **无限 combo 放任** —— 改为"让无限自带刹车"（见 §4.1 边缘情况）。

## 3. 核心玩法循环

### 3.1 三层钩子

- **Moment-to-moment（每回合 0~60s）**：抽牌 → 读敌人**亮出的意图卡（可见敌卡词条）**与其纵深位/阻挡关系 → 在（能量 + 手牌 + 纵深次序 + 词条组合 + 是否遗忘）约束下选最优出牌序列 → 结束回合 → 敌人按纵深次序打出意图卡、按词条结算 → 反馈。
- 此刻决策：**先解当前威胁（敌卡词条 + 谁能被打到、谁被前排挡住），再做词条组合与遗忘判断（要不要忘掉一张念头牌换爆发）**。
- **Session（一局 35~45min，3 层）**：选路 → 战斗 → 奖励三角 →（精英/Boss）→ 营地/商店/事件 → 变强直到层末 Boss → 下一层。
  - 此刻决策：**路线取舍 + 卡组方向（攻/防/毒/流派）**。
- **Long-term（极简跨局）**：仅 5 级纯数值难度档，不做复杂解锁/成长树。

### 3.2 一局流程（文字步骤）

```
开局（选初始卡组方向 + 难度档）
  → 第 1 层地图生成（分支节点，路线自选；首战引导层，见 §3.5）
      · 沿节点推进：普通战斗 / 精英 / 事件 / 商店 / 营地 / 宝箱
      · 每场战斗胜利：金币 + 卡三选一（可跳过）+ 概率遗物 / 药水
  → 层末 Boss #1（第 1 层梦魇领主）
  → 第 2 层（同构地图、敌人参数随层缩放；词条库已全开放，无机制门槛，见决策 J）
  → 层末 Boss #2
  → 第 3 层（敌人参数封顶，难度顶峰）
  → 层末 Boss #3（最终 Boss）
  → 通关
```

### 3.3 战斗回合流程（文字状态机）

```
回合开始：
  抽至手牌上限 · 能量回满 · 结算"回合开始"类状态（中毒等）
  敌人按其"意图槽位"容量 N 亮出本回合意图卡（N 张 affix 敌卡，卡面显示词条，效果完全可读；普通敌 N=1，精英/Boss 可 N=2）

──── 玩家阶段（任意次序，可结束）────
  出牌（按卡上词条集合结算）：
    · 攻击默认命中**纵深最近的敌人**（近端优先，近端空则次近递补）；**未带「指定」「穿透」时后排不可选中**（硬阻挡，决策 N）；带「穿透」从落点起点一路贯通到最后一个敌人；带「指定」拖拽指定任意纵深位单体（与「穿透」共存时从被指定者起贯到底，决策 O）
    · 带「消耗」的卡打出后进入消耗区（本场不再出现）
    · 带「遗忘」的卡：必须拖拽指向一张带**特定词条**的念头牌并将其**遗忘**（抹除本场），以强化/触发自身
    · 无部署：我方唯一单位 = 玩家角色本身，没有可派上场挡刀的兵种卡
  用遗物被动 / 药水
  → 结束回合

──── 敌方阶段 ────
  按"纵深近端优先"的顺序处理敌人意图：
    1. 敌人开局全部就位、位置固定，本阶段不移动（**无压境推进、无倒计时**，决策 M）
    2. 每个敌人按其"意图槽位"内的意图卡，从左往右依次打出结算：
      · 每张意图卡 = 一张 affix 敌卡，按词条集合结算，方向指向 玩家角色（唯一承伤目标）
      · 槽位容量 N（普通敌 N=1；精英/Boss 可 N=2，同亮多卡、可读多回合）
      · 攻击先被玩家格挡 / 护盾吸收，溢出到玩家 HP（没有友方单位可以挡刀）
  结算"回合结束"类状态（如再生：回 =层数 的血、随后层数自减 1）；带「保留」词条的牌本回合不进弃牌堆

──── 胜负判定 ────
  玩家 HP ≤ 0 → 负；敌方全灭 → 胜
```

### 3.4 玩家决策点清单（频率 × 依据）

| 频率 | 决策 | 信息依据 |
|---|---|---|
| 每回合 ×N | 出牌顺序、是否防御 / 消耗 | 敌人**意图卡词条** + 纵深位/阻挡关系 |
| 每回合 | 啃前排 vs 用穿透/指定处理后排威胁 | 纵深编队中各敌人威胁度（敌卡可读 + 前排/后排定位） |

| 每回合 | 预判敌人多槽位意图、做多回合规划（尤其精英/Boss N≥2） | 敌人**同亮的多张意图卡（槽位）**可读 |

| 每层 ×2~3 | 路线：冲精英赌遗物 or 绕行保血 | 当前 HP 与卡组成型度 |
| 每层 | 营地：回血 / 升级一张卡（词条数值↑或追加次要词条） | Boss 前状态 |
| 每层 | 商店买什么、删哪张 | 金币预算 |

### 3.5 教学（渐进引导 · 修复 C1 · 无层数门槛 · 决策 J）

**原则**：机制**不按层解锁**——消耗/遗忘等词条自始就在词条库与卡池里，任何层都可能获得/遇到（决策 J）。避免首局信息过载的手段是「首战引导 + 词条首触即时提示」，而非锁机制。

| 引导节点 | 触发时机 | 内容 |
|---|---|---|
| **首战引导** | 第 1 层第一场战斗 | 读敌卡意图词条、**理解"攻击默认只能命中最近敌人、后排需穿透或指定才能触及"**、看懂前排与后排的定位差异；用词条卡而非整段规则文本 |
| **词条首触提示** | 玩家**首次**获得 / 抽到 / 看到某个词条（消耗、遗忘、穿透…均适用，不限层） | 弹出该词条一句话解释，与决策 B 的 tip 互补（tip=主动悬停查看；首触提示=被动首次教学）。示例：「消耗」=打出后本场不再出现；「遗忘」=打出时选定一张带指定词条的念头牌，把它忘掉来换取爆发 |

> 早期认知负荷由**内容倾向**控制而非规则门槛：第 1 层敌人与卡组以基础词条为主、带消耗/遗忘的高阶卡出现率低；玩家熟练度上来后各层均可自然遇到全部词条。

## 4. 系统规格（纯设计 · 每系统：purpose / 玩家体验目标 / inputs / outputs / edge cases / 失败态）

### 4.1 战斗系统（整合"长条纵深 + 词条组合 + 遗忘词条"，套装遗物为被动轴）

- **purpose**：在单场战斗中整合 **长条纵深（固定阵型与硬阻挡）、词条组合结算、遗忘豪赌** 三维决策；**我方唯一单位 = 玩家角色（无部署系统）**；**敌我共用同一条 affix 结算管线**。
- **玩家体验目标**：每回合"纵深次序、词条组合、遗忘"同时可想且结果完全可读（无输出随机）；敌人的意图以可读敌卡呈现、阵型阻挡关系以站位与后排灰显呈现。
- **inputs**：手牌（含各卡词条集合）、能量、战场纵深位状态（敌编队分布与前排/后排定位）、敌人意图卡（敌卡）、遗物钩子。
- **outputs**：伤害/格挡/状态结算事件、敌人死亡、玩家 HP 变化、卡消耗（入消耗区）/遗忘（整局移除吃牌）/保留（回合结束不弃）/给予（授词）、胜负判定。
- **战斗空间（② · 长条纵深固定阵型）**：
  - 战场 = 一条**纵深通道**（题材身份见 §8：一段"梦的走廊"——近端是守梦人把守的觉醒边界，远端是梦魇翻涌而出的记忆深处）。**玩家角色位于近端**（唯一我方单位）；敌人由远及近面向玩家**按纵深位编队**（一位一敌、槽位固定）。
  - **开局就位、不再压境（决策 M）**：敌人开局全部就位、位置固定，战斗中**不移动、不逐回合压上**，亦无"距接敌 N 格"倒计时；前排敌人死亡后，默认命中目标由后一位存活敌人**自然递补**（不改变相对次序、不压缩槽位）。
  - **阵型定位（决策 N）**：敌人按阵型位分**前排**（高血低威胁的拦路/守护型）与**后排**（低血高威胁的输出/施法型）两类定位，由内容设计保证"够到后排"值得付出代价。
- **命中规则（② · 纵深次序 · 含硬阻挡）**：
  - 攻击默认命中**纵深最近的敌人**（近端优先；近端空则次近递补）。
  - **硬阻挡（决策 N）**：未带「指定」或「穿透」的单体效果**只能命中纵深最前者**，后排被前排挡住且**不可被选中**（UI 不亮后排）——这是规则而非默认值。
  - 「穿透」词条：该卡攻势词条（伤害/状态）**从落点起点一路贯通到最后一个敌人**，对各目标各结算一次（贯通比例/全额见 [PLACEHOLDER]）——是"处理被前排挡住的后排威胁"的主要手段。
  - 「指定」词条：玩家**拖拽指定任意纵深位单体**（覆盖默认最近）。
  - **「指定」+「穿透」共存（决策 O）**：起点 = 被指定的敌人，范围 = 从该敌人一路贯到最后一个——**不是优先级冲突，而是"起点 × 范围"两个正交维度的组合**。
  - **我方无单位挡刀**：敌方攻击默认直接命中**玩家角色 HP**（格挡/护盾先吸收、溢出扣血）——格挡与状态的价值因此上升。
- **词条结算流程（① · 两 pass，决策 O）**：一张卡打出 → **Pass 1 落点解析**：扫描卡上全部「落点修饰型词条」（指定/穿透）合成落点（**与词条顺序无关**）→ **Pass 2 效果结算**：按序遍历效果型词条（伤害→格挡→状态→抽牌→消耗/遗忘），共用 Pass 1 的落点逐个产出并执行 → 输出事件。**敌卡与玩家卡走同一条结算管线，仅"结算方向"相反（敌→玩家角色；玩家→敌）。** 敌方阶段排序：**纵深近端优先；每个敌人按其意图槽位内意图卡从左往右依次结算**（见 §4.2）。
- **视觉区分原则（修复 C2）**：
  - **消耗**：卡打出后**置灰移入"消耗区"**，明示"本场不再来"。
  - **遗忘**：打出时进入**拖拽态，合法目标牌高亮**，非法目标不可落点；区别于消耗的"自动离场"。
  - **敌卡意图**：玩家阶段即亮出敌卡，卡面词条可见；选中敌卡同样触发 tip（见 §4.3 / §4.4）。
- **edge cases**：
  1. **遗忘优先**：同一卡同时带「遗忘」与「消耗」→ 先结算遗忘（从整局牌组永久抹除目标念头牌），再按消耗离场。
  2. **穿透贯通**：穿透使攻势词条从落点起点开始、对其及之后每个纵深敌人各结算一次（贯通比例 [PLACEHOLDER]）；与「指定」同卡时**起点改为被指定的敌人、从它一路贯到最后一个**（决策 O，正交组合而非优先级冲突）。
  3. **指定拖拽**：「指定」词条需拖拽；松手在非法单位（含被硬阻挡的后排）→ 取消打出、能量退回。
  4. **消耗离场**：消耗词条 → 卡入消耗区（灰显），不进弃牌堆、本场不重抽。
  5. **卡组为空保底**：抽牌堆空且需抽 → 弃牌堆（不含消耗区）洗回抽牌堆；若皆空 → 不抽、不软锁。
  6. **遗忘无合法目标**：手牌无带指定词条的牌 → 该卡灰显不可打出。
  7. **纵深位互斥**：一个纵深位至多一个敌人；召唤/生成敌人落在最远空位（见 §4.2），位满则本次生成取消。
  8. **敌卡与玩家卡共用结算、方向不同**：敌卡不受能量/手牌/抽牌限制，由敌人意图卡组驱动；结算管线一致，仅目标方相反。
  9. **无限 combo 自带刹车**：任何"触发自身/递归"词条设单回合触发上限 [PLACEHOLDER]，超出静默失效。
  10. **多槽位左到右结算**：敌人 N≥2 时，其槽位内意图卡按左到右依次结算；多个敌人按"纵深近端优先"顺序，与玩家侧单卡结算共用同一条管线。
- **失败态**：
  - 若新手在 [PLACEHOLDER] 场战斗后仍无法在 30 秒内说出"这回合先处理哪个敌人（谁能被打到、谁被前排挡住）" → 纵深维度教学失败，需加强 §3.5 引导。
  - 若「遗忘」全局使用率 < [PLACEHOLDER]% 或"误当消耗"的操作 > [PLACEHOLDER]% → 两词条语义仍混淆，需强化 C2 视觉区分。
  - 若新手"阻挡关系误判率" > [PLACEHOLDER]%（误以为普通攻击可以直接打到后排）→ 硬阻挡的视觉表达不可读，需强化前排遮挡与后排灰显（与敌卡可读率同源，见 §4.2 失败态）。

### 4.2 敌人系统（敌我共用 affix 卡 · 按纵深固定阵型编队）

- **purpose**：敌我共用 affix 卡与结算管线；敌人的"意图"= 其意图槽位内将打出的敌卡（可同亮多张、可读多回合），卡面词条完全可读；敌人的**空间行为 = 纵深固定阵型**（开局就位、位置固定，无推进与倒计时——强化 P1 完全可读）。
- **玩家体验目标**：看到敌卡（含多槽位同亮的多张意图卡）与敌人在阵型中的前后位置，即能预判其伤害/状态与多回合顺序，并判断谁能被打到、谁被前排挡住，决策基于可读信息而非猜测；敌我对称降低认知负荷。
- **inputs**：敌人意图卡组（每敌一套，由 ① 词条组合模型生成）、**意图槽位容量 N（每敌 [PLACEHOLDER]；普通敌 N=1，精英/Boss 可 N=2，可随层提升）**、**纵深位与阵型定位参数（编队位数 [PLACEHOLDER]、前排/后排定位）**、层缩放参数（HP / 数值乘子）。
- **outputs**：敌卡打出 → 词条集合结算事件（方向指向玩家角色——全场唯一承伤目标）。
- **edge cases**：
  1. **共用管线、方向不同**：敌卡与玩家卡走同一结算管线，仅方向反转；敌卡不受能量/手牌/抽牌限制，由意图卡组驱动。
  2. **敌卡 affix 子集**：敌卡一般只含 攻击/防御/状态 子集，不含 遗忘/指定 等玩家向词条（Boss 可特例带 指定/召唤）。
  3. **意图取消**：敌卡在玩家阶段已亮出；若该敌人本回合被击杀/冻结，其意图卡取消、不结算。
  4. **层缩放**：同一敌卡随层提升参数（X 值乘子），不新增敌卡种类。
  5. **Boss 特例（召唤增援）**：Boss 可在**纵深最远空位**生成低阶敌人增援（受纵深位互斥约束，见 §4.1 edge 7）；召唤同样以意图卡呈现、可读可打断；不涉及任何"我方部署"语义。
  6. **意图槽位 N≥2**：敌人同时亮出 N 张意图卡（可读多回合）；敌方阶段按"纵深近端优先、每个敌人槽位内左到右"依次结算；若某槽位敌卡在玩家阶段被取消（击杀/冻结），仅该槽位卡不结算，其余照常。
  7. **阵型与意图的关系（决策 M 后修订）**：位置固定、不随回合变化，因此意图卡不受位置影响；冻结/硬控只暂停意图，不再涉及"暂停推进"（推进已被取消）。
- **失败态**：若新手在 [PLACEHOLDER] 场战斗后，看到敌卡/倒计时仍无法正确预判其效果与接敌时机的比例 > [PLACEHOLDER]% → 敌卡可读率/倒计时可读率失败，需简化敌卡词条、强化 tip 或倒计时呈现（见 §4.3/§4.4）。
- **归属**：敌人卡模板同样由 ① 统一模型生成（"能量费用(敌人侧可忽略) + 词条集合"），与玩家卡共用词条库。

### 4.3 状态词表 / 词条结构（含描述字段与 tip 规则）

> 借来的通用件直接采用，不展开论证；自组合件服务于本作融合机制。

- **词条数据结构（设计定义，非实现）**：
  `{ 名称, 可选描述文本, 效果, 卡面显示描述: 开关 }`
  - 名称：词条标识（如「消耗」）。
  - 可选描述文本：人类可读的一句话（示例：消耗 = "打出后暂时移出本场战斗"）；可不设。
  - 效果：结算语义（设计层定义，非代码）。
  - 卡面显示描述（开关）：制作期设定——开则卡面展示描述文本，关则卡面仅显示词条名称。
- **选中/悬停 tip 规则（决策 C，修正决策 B；敌我统一）**：**仅当该卡"卡面显示描述=关"（卡面只显示词条名称）时才生成 tip**，在卡旁列出该卡每个词条的效果描述（无描述则回退显示名称）；**若"卡面显示描述=开"（描述已印在卡面），则不生成 tip**——描述已在卡面，避免信息重复。
- **状态词表**：

| 词条 | 效果（一句话） | 来源 | 备注 |
|---|---|---|---|
| 力量 / 虚弱 / 易伤 / 灼烧 / 再生 | StS 通用语义（再生为本作采用） | 借来的通用件 | 直接采用；由「施加状态」词条统一施加，**属可施加数据而非独立词条**；再生 = 回合结束回 =层数 的血、随后层数自减 1 |
| 伤害 / 格挡 / 抽牌 / 获得能量 / 施加状态 | 攻势/防御/资源类核心效果 | 自组合（affix） | 见 §4.4 种子词条库 |
| 消耗（exhaust） | 打出后入消耗牌堆，本场战斗不再被抽到（战斗结束重洗后回牌组） | **自组合（affix）** | 来自 ③ 的"离场"体验，去耐力化 |
| 遗忘（erase） | 打出时须选定一张带**特定词条**的念头牌并将其**遗忘**，**从整局游戏中永久移除**（非仅本场） | **自组合（affix，④）** | 吃牌换爆发（Inscryption 思路），无 bank；梦境命名——"忘掉一段记忆换力量"（命名沿革：献祭→析构→遗忘，见决策 K/L）；**改写 RunState 牌组** |
| 穿透（pierce） | 攻势词条**从落点起点一路贯通到最后一个敌人**（贯通比例 [PLACEHOLDER]） | **自组合（affix，②·落点修饰型）** | 决定落点的**范围**；与「指定」共存时组合为"指定起点起贯到底"（决策 O） |
| 指定（aim） | 拖拽指定任意纵深位单体 | **自组合（affix，②·落点修饰型）** | 决定落点的**起点**；由原「目标」词条更名而来（避免与"目标选择"这一通用概念混淆，决策 O） |
| 保留（retain） | 带此词条的牌回合结束**不**被丢弃，仅当被打出时才离场 | **自组合（affix）** | 卡级生命周期修饰，不进 Pass 2 效果结算 |
| 给予（grant） | 打出后可选 **n 张卡**使其获得**指定词条**（例：给一张手牌添「保留」） | **自组合（affix）** | 元词条：运行时改写其他卡词条；需卡牌运行时模型支持动态增删词条 + UI 多选目标 |

### 4.4 词条组合模型（① · 内容生产核心 · 含描述系统与 tip）

- **purpose**：把卡牌从"手工单体"变成"词条组合"，用组合爆炸替代手工设计，压低内容量产成本；并统一承载"玩家卡 + 敌人卡"的生产。
- **模型（设计定义，非实现）**：
  - 一个**词条(affix)** = 原子可复用模块，结构见 §4.3：`{ 名称, 描述?, 效果, 卡面显示描述: 开关 }`。
  - 一张**卡模板** = { 名称, 能量费用, 稀有度, 词条集合[affix…] }；敌卡模板 = { 名称, 能量费用(敌人侧可忽略), 词条集合[affix…] }。
  - **内容量产三件套** = 词条库 + 卡模板（玩家/敌人，均为词条集合） + 掉落/奖励表。
- **v1 词条库（闭集，共 11 个原子词条 + 5 个状态定义；未来新增依 §5.1 扩展，不锁死）**：
  - 落点修饰（2）：穿透 / 指定（不产生效果，只决定"打谁、打多远"）
  - 攻势（2）：造成 X 点伤害（amount / times） / 施加 X 层[状态]（statusKind 枚举 + layers，通用建模覆盖 5 种状态）
  - 防御（1）：获得 X 点格挡（amount）
  - 资源（2）：抽 X 张牌（count） / 获得 X 能量（amount）
  - 特殊（4）：消耗（本场 exile） / 遗忘(特定词条，整局移除) / 保留（回合结束不弃） / 给予（授予 n 张卡指定词条）
  - 状态类（5，作为可施加/可持有的数据，由「施加状态」施加）：力量 / 虚弱 / 易伤 / 灼烧 / 再生（回合结束回 =层数 血，随后层数自减 1）
- **词条描述与 tip 交互（决策 C，修正决策 B）**：
  - 制作期开关：该词条在**卡面**是否显示描述——开则卡面展示描述文本，关则卡面只显示词条名称。
  - **仅在"卡面显示描述=关"（名称模式）时**，选中/悬停该卡才在卡旁生成 tip，列出每个词条的效果描述（无描述回退名称）；**"卡面显示描述=开"时不生成 tip**（描述已印在卡面，避免重复）。
  - 此规则对**玩家卡与敌人卡统一适用**（敌卡亮出时同样遵循名称模式才出 tip）。
- **inputs**：设计期词条库、卡模板表（玩家+敌人）、掉落表。**outputs**：运行时一张卡=其词条集合的结算。
- **edge cases**：
  1. 同一卡同时含「指定」与「穿透」→ 按 §4.1 规则合成为"起点=指定目标、范围=贯到底"，**不是优先级冲突**（决策 O）。
  2. 词条数值越界（如 X 为负）→ 校验拦截，不进运行时。
  3. 卡模板词条集合为空 → 不允许（至少含 1 个非费用词条）。
  4. "卡面显示描述=开"时不生成 tip（无论描述是否缺失，描述已印卡面）；"卡面显示描述=关"时才生成 tip，若描述缺失则 tip 回退显示名称。
- **失败态**：若设计出的卡模板中，超过 [PLACEHOLDER]% 的卡"玩家三选一从不选" → 词条组合空间未产生有效差异，需重审词条库权重。

### 4.5 地图系统

- **purpose**：用分支路径外显"风险选择"（StS 原则：地图开局可见、路线自选）。
- **节点类型**：普通战斗 / 精英 / 事件 / 商店 / 营地 / 宝箱 / Boss（层末）。
- **分布**：每层 [PLACEHOLDER] 节点，分层有向连通（保证至少一条到 Boss 路径）；每层保证 ≥ [PLACEHOLDER] 普通战、恰好 1 精英位、≥ 1 营地、末行为 Boss。
- **节点权重**：各类出现权重为 **[PLACEHOLDER]**（普通战 > 事件 ≈ 营地 > 商店 > 精英 > 宝箱）。
- **inputs**：种子、层号、当前进度。**outputs**：一层节点图与连通边。
- **edge cases**：
  1. 随机生成无可达 Boss 路径 → 重生成该层。
  2. 玩家金币为 0 且卡组无成长 → 仍保证存在战斗节点。
- **失败态**：若某层"必经战斗数"方差 > [PLACEHOLDER] → 地图生成参数失稳。

### 4.6 奖励三角 + 遗物系统（含 Balatro 式协同套装 · ⑥）

- **奖励三角 purpose**：一局内成长来源（卡 / 遗物 / 药水）。
  - 构成：卡三选一（+ 跳过）/ 遗物 / 药水。
  - 掉落：普通战→金币+卡三选一；精英/Boss→必掉遗物+卡三选一；药水按 [PLACEHOLDER] 概率。
  - edge：卡池全获取→转金币或升级；药水栏满→覆盖或转金币。
  - 失败态：三选一"跳过率" > [PLACEHOLDER]% → 卡池吸引力不足。
- **遗物系统 purpose**：第二构筑轴；不引入跨遗物耦合，奖励流派。
  - 遗物 = 被动钩子，挂到事件点（战斗开始/回合开始/打牌后/受击后/战斗胜利）。
  - **协同套装（借 Balatro）**：2~3 件为一组，单件各自独立生效、零跨遗物耦合；主题一致（如"毒流套装"三件各给微量毒增益），共同奖励某流派而非互相依赖；不强求集齐才生效。
  - **平衡约束**：禁止"读取牌序/未来抽牌"类遗物（破坏可读）；套装内不写耦合逻辑。
  - edge：同名重复获得→转金币/微量升级；钩子与消耗/遗忘交互→定义结算顺序（回合开始→打牌后→战斗胜利）。
  - 失败态：某套装胜率高于均值 > [PLACEHOLDER]% → 拆件削弱。

### 4.7 商店 / 营地

- **商店**：卖 3 卡 + 1 遗物 + 1 药水 + **删卡服务（可无限次删卡，单价递增）**。
  - **删卡价格公式（设计层）**：`删卡单价 = 基础价 + 单价增量 × 全局已删卡次数`（跨所有商店累计，不随商店刷新归零）。
  - 首次删卡付基础价；进入新商店价格**不重置**，从当前累计价继续上提；设软顶 [PLACEHOLDER] 防涨到永远买不起。
  - inputs：金币、库存表（**[PLACEHOLDER]**）、全局已删卡次数计数器；outputs：获得卡/遗物/药水/删卡（并累加全局已删卡次数）。
  - edge：删卡单价达软顶后封顶不再上涨；金币不足则不可删。
- **营地**（③ 已砍回收消耗卡，退化为二选一）：
  1. 回血 [PLACEHOLDER]%；或
  2. **升级一张卡**：在词条模型下定义为"**提升某词条数值** 或 **追加一个次要词条**"。
  - edge：无可升级卡时→仅回血可选。
  - 失败态：营地选择两动作分布极端偏斜（某动作 > [PLACEHOLDER]%）→ 另一动作无意义，需重定价。

### 4.8 事件

- **purpose**：文本风险抉择，低成本制造分支。
- **形式**：纯文本 + 2~3 选项 + 后果（扣血换卡/花钱删诅咒/赌博）。数据表驱动。
- **inputs**：事件触发、玩家选择。**outputs**：HP/卡/金币/状态变更。
- **edge cases**：
  1. 选项致牌库为空 → 保底给一张基础卡。
  2. 扣血类不允许致死 → HP 下限 1。
- **失败态**：某事件选项分布极端偏斜（某选项 > [PLACEHOLDER]%）→ 该选项无意义。

### 4.9 难度档（Ascension 简化 · 5 级纯数值缩放）

- **purpose**：跨局难度，参数化不堆内容（Balatro 思路：只加数字）。
- **5 级**：敌人数值乘子 / 精英出现率 / 初始 HP 下调 / 逐层负面规则，逐级叠加——纯配置（对敌卡参数同样生效）。
- **inputs**：难度等级。**outputs**：全局数值缩放。
- **edge cases**：等级边界（1 与 5）不出现负 HP / 零收益；高等级下地图仍保证可通关路径。
- **失败态**：最高档通关率 < [PLACEHOLDER]% → 档位过苛。

## 8. 世界观与场景（《梦境守望》Dreamkeep · 决策 L 丰富稿）

> 本章定位：为机制提供**叙事身份与氛围**，只做设定与场景描写、不新增任何系统。所有描写与 §3/§4 的规则一一对应：卡牌 = 念头（记忆残片），遗物 = 记忆锚（守护物），状态 = 梦的印记；**我方单角色 = 守梦人（沉睡意识中唯一清醒的自我），无兵可派在叙事上是"清醒只够维持你一个"的结果**。

### 8.0 选题理由（为什么是梦境守望 · 答辩口径）

- **机制红利**：本作战斗空间的核心是"敌人沿纵深排布成阵、前排挡住后排、玩家守近端"。梦境给出零解释成本的同一结构：**梦魇从记忆深处浮现，层层叠叠挤在同一段走廊里**，"谁挡在谁前面"就是你够不够得到它的距离；三层地图 = 三层越陷越深的梦域。选它不需要把世界观"翻译"给玩法听——它就是玩法本身的样子。
- **词汇表服务词条组合模型**：念头/记忆天然是碎片化模块——伤害/格挡/状态/消耗/穿透/目标/遗忘都有不违和的梦语表达（见 §8.4），卡名、敌名、事件名的素材库（回忆、执念、旧梦、噩梦生物）丰富且免费。
- **单人可承载**：梦境意象（光斑、记忆碎片、色雾、低多边形梦物）对图标化卡牌友好，美术不需要写实精度；答辩演示的视觉记忆点强。
- **皮肤可整体替换**：题材与机制**解耦**——§8 全章、卡面/敌人/遗物命名、词条题材名是唯一会随题材变动的层；选择梦境守望**不基于毕设专业身份**，而是上述玩法/成本/辨识度理由。若日后要换皮肤，机制、数值、架构零改动。

### 8.1 世界设定（一段话）

有人在很深很深地睡着。没有人知道 TA 是谁——你只知道他是"沉睡者"，而你是他意识里**最后一段仍然清醒的自我**：一个单薄的影子，被称作守梦人。近来他的梦开始不对劲：梦魇从记忆的断层里涌出来，沿着一条条梦的走廊，向"清醒"的边界蔓延。若它们抵达边界、撕开那道口子，沉睡者会被惊醒——或更糟，从此分不清梦与现实。你挡在边界前，手里只有一小叠念头：你记着的东西，就是你的武器与护甲。每次失败，你会从下一个夜晚重新沉入同一场梦（肉鸽式的重来；难度档 = 梦魇更浓，或沉睡者的睡眠更浅、你能记住的念头更少）。

### 8.2 长条战斗空间：一段梦的走廊（纵深 = 梦魇离清醒还有多远）

- **叙事身份**：每场战斗 = 一段**梦的走廊**——近端是你守着的"觉醒边界"（那层薄薄的光膜），远端是梦魇不断浮出的**记忆断层**。纵深不是背景板，而是**梦魇已经翻搅到多浅的地方**：敌人离你越近，说明它已接近苏醒的世界；而堵在你与后排之间的那一只，会替身后所有梦魇挡下你的念头。
- **玩家在空间中的位置**：你站在觉醒边界前——最后一个清醒的哨位。身后是你够不到、也绝不能失守的醒来的世界。**没有单位可派**是自洽的：清醒的意识只够维持你一个，无法分给任何幻影。
- **敌人 = 浮出的梦魇**：它们不需要"走"——梦魇一旦浮现，就钉死在这段走廊的某个位置上，从头到尾守在那儿。前排那些厚重而迟钝的，是**堵在路中间的旧物**；后排躲在其身后的，是**真正在低语的那一批**——你想够到它们，得先有一道能穿透的念头，或亲手指定一个落点。
- **战斗氛围基调**（可呈现层）：近端是安静、稳定的一线光，远端是翻涌的色雾与变形的轮廓；每击退一只梦魇，那一段走廊恢复静谧、色彩落回梦里——它被推回了深处。战斗入场给一句一行式"梦呓"交代局势（如 `> 走廊第七扇门后：有什么在挠门`），不打断回合节奏。

### 8.3 三层梦域（对应 §3.2 的三层地图）

| 层 | 梦域（场景身份） | 敌人强度与节奏（参数随层缩放 · 词条无层数门槛，见决策 J） | 场景描写基调（氛围） |
|---|---|---|---|
| **第 1 层** | **浅梦·阈限走廊**（梦的最外层：还能听见外界声音的回响、白噪音、近几日的浮光） | 敌参数乘子最低；梦魇细碎、编队以近端即时威胁为主，是**首战引导层**（见 §3.5）；层末 **Boss #1** | 白噪的微光、半透明的日常碎片缓缓飘过；走廊尽头偶尔传来真实世界的模糊声响。敌人是"窃忆的影""失眠的哨子""门槛上的小梦魇"——威胁不大，但已学会**结伴压近**。色调：浅眠的雾蓝 + 一点暖光 |
| **第 2 层** | **深梦·旧事回廊**（更私密的记忆：泛黄的旧事、未能说出口的话、反复做的同一个梦） | 敌词条组合复杂度上升，精英开始出现**多槽位意图（N≥2）**；层末 **Boss #2** | 光暗下来，色调转向琥珀与靛青的旧梦色；执念像潮水漫过走廊，墙上浮着模糊的脸与褪色的对话。敌人是"旧日的回声""说不出口的话""反复重播的那一夜"——在这里，**不可逆的放下**成为日常（消耗类念头的自然共鸣）。基调：黏稠、低回、私密 |
| **第 3 层** | **梦核·最初的梦**（整个梦的原点：沉睡者不愿面对、也绕不开的东西） | 敌参数封顶、后排高威胁敌人占比更高 [PLACEHOLDER]；Boss 级敌人常态 N≥2；层末 **Boss #3（最终 Boss）** | 光几乎熄灭，唯一的声响是像心跳一样的节拍；走廊变成了某种巨大而古老的东西的内部。**Boss = 最初的梦魇**——它是这整场梦第一次出现裂缝时诞生的存在，学会了同时展开多张意图、在走廊深处调度增援（意图槽位 N≥2）。基调：压迫、寂静、不容喘息 |

> **层末 Boss（决策 I）**：每层末尾均有一场 Boss 战——第 1 层 = 把守浅梦与深梦之间"阈限"的梦魇领主；第 2 层 = 旧事回廊的"执念宿主"；第 3 层 = 梦核的"最初之魇"（最终 Boss，强度最高）。每击败一名层末 Boss，该层梦域归于平静——梦魇被推回更深处，沉睡者离安稳的醒更近一步。
> **词条无层数门槛（决策 J）**：消耗/遗忘等全局词条在三层都会自然出现，三层差异只在场景、敌数值与编队复杂度，不在机制；场景描写只承担词条的**叙事共鸣**（如遗忘 = 把一段记忆亲手抹去换力量：你忘掉一张念头牌，它化作此刻的爆发），不承担"解锁"职责。
> **层间选路**：沿地图（§4.5）移动时，场景由浅梦的走廊逐级沉入深梦；选路在叙事上 = 你决定这一晚先安抚哪一段记忆。

### 8.5 统一性与篇幅纪律（避免世界观失控）

- 命名域统一：敌人/卡牌/遗物命名共用同一词汇域（梦/记忆/睡眠/旧事），禁止跳出题材的命名。
- 场景描写**只承载已被 §3/§4 定义的机制**，不得借氛围之名悄悄引入新玩法。
- 设定文本总量克制：代入感来自"名词与规则的一致"，不靠长篇叙事文本（延续 §3.5"用词条卡而非整段规则文本"原则）；上述场景描写即各层可用的文案上限。
- 单角色自洽：任何文案不得暗示守梦人能召唤/指挥幻影集群；"下一夜再入梦"指跨局重试，不代表局内分身。
- 皮肤可替换：本章与题材命名是唯一皮肤层；换题材时仅替换本章与命名表（§8.4），机制/数值/架构不动。
